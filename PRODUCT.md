# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Tech recruiters, hiring managers and graduate-program screeners in Brisbane and Australia who open the link from a resume, LinkedIn profile or job application and decide within seconds whether Vy is worth an interview. Often on a phone from LinkedIn, sometimes on a desktop beside an applicant tracking system.

## Product Purpose

The personal portfolio of Vy Truong (also Vivian), a Bachelor of IT (Software Development) student at Griffith University, Brisbane, graduating November 2027. It exists to win software development internships, WIL placements and graduate roles (also data/BA and QA). Success is a recruiter opening the resume or a project and contacting her.

## Positioning

What a recruiter should remember: Vy builds real products and finishes them, with tests, CI and working demos, and she builds things that are useful to Queensland (an interactive Queensland railway map, a live TransLink train map in progress, Queensland-relevant weekly projects).

## Operating Context

Static site on GitHub Pages at vy-trg.github.io/portfolio. Linked from her resume, LinkedIn Featured section and cover letters. Recruiters skim, open the resume PDF, open GitHub repos and live demos.

## Capabilities and Constraints

- Scope of the redesign is the portfolio page only; the project repos and their live demos stay untouched.
- Stack: plain static HTML, CSS and JavaScript in one index.html, no framework, free hosting only (GitHub Pages).
- Availability: full-time until end of February 2027, then 48 hours per fortnight during semester.

## Brand Commitments

- Name: Vy Truong. Email vivian.trg3@gmail.com, GitHub github.com/vy-trg, LinkedIn linkedin.com/in/vy-trg.
- Voice: plain, direct, honest, slightly warm; no overclaiming, no buzzwords, no em-dash overuse.
- Visual direction (Oct 2026): the user chose the category standard, a clean conventional developer portfolio executed at full fidelity, over themed directions. She asked Claude to pick the craft bar: leerob.com, emilkowal.ski and paco.me (minimal, typography-led personal sites). The old dark-navy template look with mono labels and card grids is retired because it reads like every other portfolio.

## Evidence on Hand

- Projects with real outcomes: JavaFX Tetris (96/100, 21 unit tests run by GitHub Actions, gameplay video in assets/), EnergyCheck (High Distinction, team leader, live demo), Queensland Railway Interactive Map (40/40, live demo), Kakadu Kitchen Database (ERD image), Power BI coursework (files not public), Space Shooter, Python Data Analysis, REST Countries API app.
- Assets: assets/portrait.webp, project screenshots, Vy_Truong_Resume.pdf.
- In progress, not finished: Pomodoro focus tracker (Node.js, Express, PostgreSQL) and a live Queensland train map from TransLink's real-time feed.
- No testimonials, employers' quotes or metrics beyond grades and test counts; none may be invented.

## Product Principles

- Proof before claims: every skill named is backed by a project on the page.
- The first viewport answers who, what she builds, and that she is available now.
- Recruiters act fast: resume, email, GitHub and demos are always one tap away.
- Only finished work is presented as finished; work in progress is labelled as such.

## Accessibility & Inclusion

Readable at a glance on a phone; WCAG AA contrast, keyboard reachable links, reduced-motion respected.
